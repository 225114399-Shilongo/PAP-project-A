Municipal Financial Management System (MFMS)

1. Project Overview

The Municipal Financial Management System (MFMS) is a C program we developed for PAP521S – Programming in Practice at NUST.

Our system helps manage municipal employees, departmental budgets, suppliers, assets, and reports. The project allowed us to apply the C programming concepts we learned in class to a practical problem.

2. Technologies Used

* C (C99)
* GCC Compiler
* Visual Studio Code
* Git and GitHub

3. System Features

Our system consists of the following modules:

Main Menu: Allows us to navigate through the different modules.
Employee Management: Allows us to add, display, and search for employees and calculate salaries.
Budget Management: Allows us to manage departmental budgets, record expenditure, and calculate remaining budgets.
Supplier Management:Allows us to add, display, search, and compare suppliers.
Asset Management: Allows us to register, display, and search for municipal assets.
Reports: Allows us to view reports on employees, budgets, suppliers, and assets.

4. How to Run the System
We developed and tested our program on Windows using GCC.

Step 1: Open the project folder in Visual Studio Code.

Step 2: Open the terminal and check the C files.
dir *.c

Step 3: Compile the program.
gcc *.c -o MainMenu


Step 4: Run the program.
.\MainMenu
